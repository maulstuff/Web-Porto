# Atr alick — Personal Portfolio

Personal portfolio starter inspired by the Dribbble screenshot shared in the conversation. The design uses a dark green-glow hero, clean light sections, service cards, an asymmetric project gallery, testimonials, articles, and an oversized footer wordmark.

## Run locally

1. Install Node.js 20.9 or newer.
2. Extract this folder and open it in VS Code.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Customize

- Update the name, role, stats, service cards, project data, testimonial, and article cards in `src/app/page.tsx`.
- Replace the Unsplash image URLs with your own work when ready.
- Global styles and responsive layouts are in `src/app/globals.css`.
- Metadata is in `src/app/layout.tsx`.

## Deploy to Vercel

Push the project to GitHub, import the repository in Vercel, and deploy with the default Next.js settings.

The current text and project entries are demo content. Replace them with accurate personal information before publishing.
